# Mallank Gogri Portfolio

Recruiter-facing portfolio for Mallank Gogri, built with Next.js.

## Structure

This is a single Next.js application. App routes live in `app/`, reusable UI lives in `components/`, and downloadable assets live in `public/`.

## Getting Started

Install and run from the repository root:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying files in `app/` and `components/`.

## Checks

```bash
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env.local` when local configuration is needed.
